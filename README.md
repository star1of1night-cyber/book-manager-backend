# 📚 مكتبتي — تطبيق إدارة الكتب المدرسية

تطبيق شخصي مجاني يحوّل صور الكتب المدرسية إلى ملفات PDF قابلة للتحليل والتصنيف، ويجيب عن أسئلتك حول محتواها باستخدام الذكاء الاصطناعي.

## ✨ المزايا
1. تصوير صفحات الكتاب وتحويلها تلقائيًا إلى ملف PDF واحد.
2. استخراج النص من الصور (OCR) وتصنيفه حسب المادة والصف في قاعدة بيانات.
3. طرح أي سؤال عن محتوى كتاب معيّن والحصول على إجابة بالذكاء الاصطناعي.
4. يعمل كموقع ويب، ويمكن "تثبيته" كتطبيق على الجوال (PWA) من المتصفح مباشرة.
5. مجاني بالكامل عند استخدام الباقات المجانية للخدمات المذكورة أدناه.

---

## 🧩 مكوّنات المشروع

```
book-manager/
├── frontend/     ← واجهة الاستخدام (HTML/CSS/JS) — تُرفع على أي استضافة ثابتة
└── backend/      ← الخادم الخلفي (Node.js/Express) — يحتاج استضافة تدعم Node
```

هذا الفصل بين الواجهة والخادم ضروري: أي معالجة صور، اتصال بقاعدة بيانات، أو استدعاء خدمات AI **يجب** أن يحدث من خادم، لأسباب أمنية (لا يمكن وضع مفاتيح API سرّية داخل كود يعمل في متصفح المستخدم مباشرة).

## 🚀 خطوات التشغيل والنشر

### الخطوة 1: تجهيز الحسابات المجانية المطلوبة

| الخدمة | الغرض | رابط التسجيل |
|---|---|---|
| MongoDB Atlas | قاعدة بيانات لتخزين الكتب | https://www.mongodb.com/cloud/atlas/register |
| OCR.space | تحويل صور الكتاب إلى نص | https://ocr.space/ocrapi/freekey |
| Anthropic أو OpenAI | الإجابة عن الأسئلة بالذكاء الاصطناعي | https://console.anthropic.com/ أو https://platform.openai.com/ |

بعد التسجيل في كل خدمة، احتفظ بالمفاتيح (API Keys) التي ستحصل عليها.

### الخطوة 2: نشر الخادم الخلفي (Backend)

أسهل خيار مجاني: **Render.com**

1. أنشئ حسابًا على https://render.com
2. ادفع مجلد `backend/` إلى مستودع GitHub خاص بك (أو استخدم رفع مباشر إن توفر).
3. من Render: New → Web Service → اختر المستودع.
4. اضبط:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. في تبويب Environment، أضف كل المتغيرات الموجودة في ملف `backend/.env.example` بقيمها الحقيقية (روابط ومفاتيح API الخاصة بك).
6. بعد النشر، ستحصل على رابط مثل: `https://your-app.onrender.com` — احتفظ به.

> بدائل أخرى تدعم Node.js مجانًا: Railway.app، Fly.io، Cyclic.sh

### الخطوة 3: نشر الواجهة الأمامية (Frontend)

أسهل خيار مجاني: **Netlify** أو **Vercel** أو **GitHub Pages**

1. ارفع مجلد `frontend/` كموقع ثابت (Static Site) على أي من هذه الخدمات.
2. لن تحتاج أي إعداد بناء (Build) — فقط اسحب وأفلت المجلد على Netlify مثلاً، أو اربطه بمستودع GitHub.
3. بعد النشر ستحصل على رابط مثل: `https://your-library.netlify.app`

### الخطوة 4: ربط الواجهة بالخادم

1. افتح رابط موقعك.
2. اذهب إلى تبويب **"الإعدادات"**.
3. الصق رابط الخادم الخلفي الذي حصلت عليه في الخطوة 2 (مثال: `https://your-app.onrender.com`).
4. اضغط **حفظ** — سيتحقق التطبيق من الاتصال تلقائيًا.

🎉 التطبيق جاهز للاستخدام الآن من أي متصفح، ويمكنك أيضًا "تثبيته" على شاشة جوالك الرئيسية:
- **أندرويد (Chrome):** قائمة المتصفح ⋮ ← "تثبيت التطبيق"
- **آيفون (Safari):** زر المشاركة 🔗 ← "إضافة إلى الشاشة الرئيسية"

## 💻 التشغيل محليًا (للتجربة على جهازك قبل النشر)

### تشغيل الخادم الخلفي
```bash
cd backend
cp .env.example .env
# افتح .env وأدخل مفاتيحك الحقيقية
npm install
npm start
```
سيعمل الخادم على: `http://localhost:5000`

### تشغيل الواجهة الأمامية
افتح `frontend/index.html` مباشرة في المتصفح، أو استخدم أي خادم ملفات بسيط:
```bash
cd frontend
npx serve .
```
ثم من تبويب "الإعدادات" داخل التطبيق، ضع الرابط: `http://localhost:5000`

## 🔒 ملاحظات مهمة

- **الخصوصية:** بما أنه تطبيق شخصي بدون نظام تسجيل دخول، يُنشأ معرّف مستخدم عشوائي ويُحفظ في متصفحك (localStorage). كتبك مرتبطة بهذا المعرّف فقط. إن مسحت بيانات المتصفح، ستحتاج لإعادة ربط الحساب (الكتب تبقى محفوظة في قاعدة البيانات لكن لن تظهر إلا بنفس المعرّف).
- **التكلفة:** جميع الخدمات المذكورة لها باقات مجانية كافية للاستخدام الشخصي (عدد محدود من الكتب/الأسئلة شهريًا). تجاوز الحدود المجانية قد يتطلب ترقية مدفوعة من مزوّد الخدمة نفسه.
- **دقة OCR:** جودة استخراج النص تعتمد على وضوح الصورة والإضاءة عند التصوير — يُفضّل تصوير الصفحات بشكل مستقيم وبإضاءة جيدة.

## 🛠️ التخصيص لاحقًا

- لدعم "تسجيل دخول" حقيقي متعدد الأجهزة، يمكن إضافة نظام مصادقة (مثل Firebase Auth) لاحقًا.
- لتحسين دقة OCR للنصوص العربية المطبوعة في الكتب المدرسية، جرّب أيضًا خيار Google Cloud Vision الموجود جاهزًا في `backend/config/ocrService.js`.
- يمكن تبديل مزوّد الذكاء الاصطناعي بين Claude وOpenAI بتغيير سطر واحد فقط (`AI_PROVIDER`) في ملف `.env`.
